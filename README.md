# realmeUIdebloater
his script allows you to debloat the Realme UI on your Android device. 
It helps you remove unnecessary pre-installed apps without causing phone crashes. 
Please note that this script is designed for Realme UI based on Android 12 specifically and may or may not work with other Android versions.
In case of any issue you could use reloader.bat

Features
--------
- Debloat Realme UI by removing unnecessary pre-installed apps.
- Preserves essential components to ensure stability and prevent phone crashes.
- Easy to use and customize according to your preferences.

Requirements
------------
- ADB (Android Debug Bridge) installed on your computer.
- USB Debugging enabled on your Android device.

Usage
-----
1. Connect your Android device to your computer using a USB cable.
2. Open a terminal or command prompt on your computer.
3. Ensure that your computer has ADB properly set up and recognized your device.
4. Clone or download this repository to your computer.
5. Open the `debloater.bat` file and review the list of apps to be removed.
6. Customize the list by commenting out or uncommenting specific lines according to your preferences.
7. Save the changes to the `debloater.bat` file.
8. In the terminal or command prompt, navigate to the directory where the script is located.
9. Run the script and you're done
